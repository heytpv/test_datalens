В рамках проекта был создан интерактивный дашборд для анализа показателей продаж и выявления основных тенденций

Что было сделано: 
1. подготовлены и обработаны исходные данные;
2. рассчитаны основные показатели продаж;
3. построены графики и таблицы для анализа данных;
4. добавлены фильтры для интерактивного анализа;
5. оформлен итоговый дашборд;
6. проанализированы динамика и структура показателей.
